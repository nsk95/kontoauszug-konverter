Danke für Ihren Kauf!

Ihr Freischaltcode für 50 Seiten kommt zusätzlich per E-Mail an die Adresse, die Sie beim Bezahlen angegeben haben. Das dauert normalerweise nur wenige Minuten, in der Startphase spätestens 24 Stunden. Öffnen Sie nach dem Kauf die Rückleitung von Stripe, um den Code sofort abzurufen.

Jetzt im Konverter einlösen

Code von Hand einlösen, z. B. auf einem anderen Gerät
  1. Öffnen Sie den Konverter.
  2. Klicken Sie unter dem Ablagefeld auf „Freischaltcode“.
  3. Fügen Sie den Code ein (beginnt mit KK1.) und klicken Sie auf „Einlösen“.

Neue Guthaben werden online verwaltet. Derselbe Code öffnet auch in einem anderen Browser das verbliebene Guthaben und füllt es nicht erneut auf. Bereits früher offline eingelöste Guthaben bleiben in ihrem bisherigen Browser erhalten. Ihre Kontoauszüge werden weiterhin nur lokal verarbeitet.
