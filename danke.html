Kontoauszug-Konverter

Danke für Ihren Kauf!

Ihr Freischaltcode für 50 Seiten kommt per E-Mail an die Adresse, die Sie beim Bezahlen angegeben haben. Das dauert normalerweise nur wenige Minuten, in der Startphase spätestens 24 Stunden.

So lösen Sie den Code ein

  1. Öffnen Sie den Konverter.
  2. Klicken Sie unter dem Ablagefeld auf „Freischaltcode“.
  3. Fügen Sie den Code ein (beginnt mit KK1.) und klicken Sie auf „Einlösen“.

Das Guthaben gilt in dem Browser, in dem Sie den Code einlösen. Ihre Kontoauszüge werden weiterhin nur lokal verarbeitet.
