2. Leistung

Der Konverter wandelt PDF-Kontoauszüge in Ihrem Browser in CSV, CAMT.053, MT940 und DATEV-Buchungsstapel um. Die Verarbeitung findet ausschließlich auf Ihrem Gerät statt; Ihre Auszüge werden nicht an uns übertragen. Jeder Browser kann 3 Seiten kostenlos umwandeln. Damit können Sie vor dem Kauf prüfen, ob Ihre Auszüge erkannt werden.

Gegenstand des Kaufs ist ein Freischaltcode (digitaler Inhalt) für das Paket „50 Seiten“. Nach dem Einlösen kann der Browser, in dem der Code eingelöst wurde, weitere 50 PDF-Seiten exportieren. Abgerechnet wird erst beim Export, je PDF-Datei einmal; dieselbe Datei erneut zu exportieren kostet nichts. Das Guthaben verfällt nicht.
